# Student Management System

A simple web application to manage student records using Node.js, Express, MongoDB, and EJS.

## 🚀 Features
- Add new students
- View all students
- Update student details
- Delete student records

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB
- EJS
- HTML, CSS

## 📂 Project Structure
- models/ → Database schemas
- views/ → EJS templates
- public/ → CSS and static files
- app.js → Main server file

## ▶️ How to Run
1. Clone the repository
2. Install dependencies:
   npm install
3. Start the server:
   node app.js
4. Open browser:
   http://localhost:3000
